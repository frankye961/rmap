# Project instructions

- This is a learning project. Implement only the explicitly requested task.
- The current task authorizes scaffolding and documentation only.
- Prefer simple functions, structs, and enums.
- Keep changes small and explain their purpose.
- Keep CLI parsing, scanning, reporting, and AI responsibilities separate.
- Do not add dependencies without a concrete need in the requested task.
- Do not implement scanning, concurrency, host discovery, raw packets, or AI calls unless requested.
- Do not make live scans or AI requests merely to validate scaffolding.
- Keep secrets out of commits, logs, and reports.
- Preserve measured results independently of AI interpretation.
- Preserve existing user changes.
- Run formatting and relevant checks after changes.
- Commit and push only when authorized by the current request.
- Report validation results and unfinished work accurately.
