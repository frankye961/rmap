# AI interpretation and CVE retrieval

`--ai` requests a separate DeepSeek interpretation after the measured scan report has printed. The scanner itself does not call AI. If configuration, retrieval, or the model request fails, the scan results remain visible. Rig supplies the model client and agent; the project retrieves local advisory text and adds it to the model request. This is retrieval-augmented generation (RAG) with exact-version text matching rather than embeddings or a vector database.

Set `RMAP_AI_API_KEY` and `RMAP_AI_MODEL` in a `.env` file in the current working directory or export them in the shell. Exported values take precedence. `RMAP_AI_BASE_URL` optionally overrides Rig's DeepSeek endpoint; `RMAP_AI_TIMEOUT_MS` defaults to 15000. The optional `RMAP_CVE_FILE` points to a UTF-8 file. [`.env.example`](../.env.example) documents the names and can be copied to `.env`. The file is read only when `--ai` is used. Legacy `RUST_NMAP_*` names remain accepted. Nonempty environment values take precedence over file values; within each source, the new `RMAP_*` name takes precedence. Credentials never enter the prompt or report.

The advisory file is tab-separated with five fields per line: `CVE-ID`, product, exact version, HTTPS source URL, and short description. Lines starting with `#` are ignored. Keep this file curated from authoritative advisories and verify affected-version metadata independently. The reader limits the file to 1 MiB, takes at most five matches, and matches only product/version text actually observed in an open port's banner or HTTP `Server` header. A match is a possible lead, not a confirmed vulnerability; package maintainers may backport fixes without changing the advertised version.

The prompt includes at most eight open-port observations, 160 characters of each observation, and the selected advisory candidates. It asks DeepSeek to separate facts from hypotheses, cite only supplied CVE IDs, and recommend verification. A successful TCP connection does not establish service identity or vulnerability. A timeout does not prove a host is offline or a port is filtered. Target banners and advisory text are untrusted data, not instructions. The model's prose is displayed separately from measured results and source-linked advisory candidates.

The request disables DeepSeek thinking mode because the report needs a short final answer under a bounded output limit. Provider parse errors report their category and JSON location without printing the provider body or credentials.

The AI response model is `AiAnalysis`: generated interpretation plus the independently retrieved `CveCandidate` records. No live scan or AI request is required for build or unit-test validation.
